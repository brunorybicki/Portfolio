# Portfolio
This repository contains the source code for my personal portfolio website.
\
The website provides a brief introduction to my background, experience, and interests, as well as links to my LinkedIn and GitHub profiles.

## Live Demo
View the portfolio on [GitHub Pages](https://brunorybicki.github.io/Portfolio/).

## Features
- **Personal Introduction:** Provides a brief overview of my background, experience, and interests.
- **Professional Links:** Includes direct links to my LinkedIn and GitHub profiles.
- **Responsive Design:** Adapts the layout for desktop and mobile devices.
- **Custom Styling:** Uses a gradient background, custom graphics, and a consistent visual design.
- **Lightweight Website:** Built entirely with HTML and CSS without JavaScript.

## Project Structure
- `index.html`: Contains the structure and content of the website.
- `styles.css`: Defines the layout, styling, and responsive behavior.
- `assets/`: Contains the graphics and icons used by the website.

## Technologies
The website is built using:
- HTML
- CSS

## Usage
To run the website locally:

1. Download or clone the repository.
2. Open the `index.html` file in a web browser.
